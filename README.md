# TJU-Military-Exam（顶层个人数据仓库）

> 本仓库是 **个人数据与使用记录层**,与代码仓库分离。
> 代码与工具链在 `工作流/` 子目录,是独立的 Git 仓库,托管于 <https://github.com/WhatYearIsNow/TJU-Military-Exam>。

## 用途

军理(军事理论)考试的资料整理:试卷图片、OCR 结果、AI 作答对比、终版答案与题库文档。用于学习资料整理和结果复核,自动生成的答案不等于客观真值,红/黄标记题必须人工确认。

## 目录结构

```text
.
├── 工作流/           独立代码仓库(OCR + 题库检索 + 交叉验证工具,见其 README)
├── 测试/             历次模拟测试的题目图片、AI 回答与终版答案
├── 模拟/             模拟试卷图片与校对
├── 考试/             正式考试题目图片与 AI 作答对比
├── 军理单元题与见面课题库.md   题库整理(文本)
├── 新题库.md                  题库整理(文本)
├── output/           文档输出(如使用说明 PDF)
└── README.md         本文件
```

## Git 策略

- **入库**:题库文档、校对与答案 Markdown、本 README。
- **不入库**(见 `.gitignore`):个人试卷图片、`.venv`、缓存、日志、`config.yaml` 等运行产物——遵循 `工作流/CLAUDE.md` 约定。
- 顶层与 `工作流/` 是两个独立仓库,互不嵌套提交。
